# University application and bursary funding.
#
# The mediator opens a later item only when each incoming rule has been decided.
# "*" matches any successful completion. "rejected" matches reject(), not the
# reason text. A sub-process finishes with outcome "completed", so a rule that
# leaves a process uses "*".
#
# Rejecting CAPTURE or VERIFY_ID rejects the application: nothing recovers, so
# the parent is rejected and REVIEW and FUNDING are cancelled.
# Application documents (VERIFY_DOCS) are not the bursary file. FUNDING_DOCS
# opens with funding and must succeed before approval. Rejecting FUNDING_DOCS
# opens the appeal and cancels approval and payment.
# Complete APPROVE with "approved" to pay. Reject APPROVE to open the appeal
# and cancel payment. Any other APPROVE outcome cancels both PAY and APPEAL.
#
# Roles are the participant role strings. Services are ExternalService::name().
# incomeBracket is read from instance data. A missing or unknown value uses
# FinanceManager. low, mid and high select BursaryOfficer, FinanceManager and
# BursaryCommittee.

DEFINITION
